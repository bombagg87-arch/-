# ГРОЗОВОЙ КЛИНОК

Короткометражный фильм (≈2 минуты) по мотивам мира Боевого континента: мальчик, чей дух —
меч из молнии.

**Смотреть:** откройте `grozovoy-klinok-film.html` — это весь фильм в одном файле.
Веб-версия с отдельными ассетами: `film/index.html`.

## Что внутри

| Файл | Описание |
|---|---|
| `grozovoy-klinok-film.html` | **один файл — весь фильм**: кадры и озвучка встроены внутрь, открывается без сервера и без интернета |
| `film/index.html` | версия для веба (те же кадры и звук отдельными файлами) |
| `film/script.md` | сценарий: 8 глав, реплики, кадры, персонажи, устройство мира |
| `film/img/*.jpg` | 8 кадров-постеров (сгенерированы для фильма) |
| `film/audio/*.mp3` | закадровая озвучка по главам (~2:00 суммарно) |
| `film/build_single.py` | сборка автономного одностраничного файла |

## Как смотреть

- **Одним файлом:** скачайте `grozovoy-klinok-film.html` (3,9 МБ) и откройте в браузере — можно пересылать в мессенджере.
- **Через сервер:** `python3 -m http.server 8000 --directory film` → http://localhost:8000
- **Пересобрать автономную версию:** `python3 film/build_single.py`

## Управление

- `пробел` — пауза / продолжить
- `←` `→` — предыдущая / следующая глава
- `S` — субтитры
- `M` — звук атмосферы (ветер, дождь, гром)
- `F` — полный экран
- клик по полосе прогресса — перемотка на любую главу

## Технологии

Чистый HTML/CSS/JS без зависимостей: Ken Burns-анимация кадров, кроссфейды через «занавес»,
синхронные субтитры по таймингу озвучки, canvas-дождь, случайные вспышки молний, тряска камеры
и синтезированная через WebAudio атмосфера (ветер, ливень, раскаты грома).
