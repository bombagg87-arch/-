# Боевой континент

Песня, собранная целиком в коде: эпик-рок гимн на русском языке.

- `song/lyrics.md` — текст, структура, гармония
- `song/engine.py` — синтез инструментов и микс (numpy, без сэмплов)
- `song/render.py` — сборка трека: секции, вокал, мастер-обработка
- `song/analyze.py` — анализ высоты тона вокальных дорожек
- `song/out/` — готовый микс (wav + mp3)

## Запуск

```bash
python3 -m venv .venv && .venv/bin/pip install numpy lameenc matplotlib
.venv/bin/python song/render.py          # готовый трек (нужен вокал в song/vocal/)
.venv/bin/python song/render.py --inst   # только инструментал
```

## Как это сделано

1. **Инструментал** синтезируется с нуля: кик/снейр/хэт/томы из шума и синусов,
   дисторшн-гитары из пилообразных волн с PolyBLEP и tanh-перегрузкой,
   бас, пэды с расстройкой, лид-партия, райзеры, свёрточный реверб на
   самодельных импульсных откликах.
2. **Аранжировка** — 12 секций по фиксированной сетке тактов (132 BPM, 4/4),
   гармония в Dm: куплет `Dm–Bb–F–C`, припев `Bb–C–Dm–A`.
3. **Вокал** — речевой синтез, обработанный как вокальная дорожка:
   ФВЧ, эквалайзер, эксайтер, компрессия, сатурация, реверб и дилей.
   Голос не поёт, а читает — это осознанный приём: боевой речитатив поверх
   гитарного гимна.
4. **Мастер** — эквалайзер (срез саба, презенс), мягкий лимитер, нормализация.
