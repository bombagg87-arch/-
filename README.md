# ГРОЗОВОЙ КЛИНОК

Короткометражный фильм (≈2 минуты) по мотивам мира Боевого континента: мальчик, чей дух —
меч из молнии.

**Смотреть:** откройте `film/index.html` (или запустите сервер: `python3 -m http.server 8000 --directory film`
и зайдите на http://localhost:8000).

## Что внутри

| Файл | Описание |
|---|---|
| `film/index.html` | сам фильм: киноплеер с озвучкой, субтитрами, грозой, дождём и титрами |
| `film/script.md` | сценарий: 8 глав, реплики, кадры, персонажи, устройство мира |
| `film/img/*.jpg` | 8 кадров-постеров (сгенерированы для фильма) |
| `film/audio/*.mp3` | закадровая озвучка по главам (~2:00 суммарно) |

## Управление

- `пробел` — пауза / продолжить
- `←` `→` — предыдущая / следующая глава
- `S` — субтитры
- `M` — звук атмосферы (ветер, дождь, гром)
- `F` — полный экран
- клик по полосе прогресса — перемотка на любую главу

## Главы

0. Пролог · Титул
1. Континент
2. Пустой
3. Гроза
4. Мастер
5. Арена
6. Десять тысяч клинков
7. Эпилог · Грозовой клинок

## Технологии

Чистый HTML/CSS/JS без зависимостей: Ken Burns-анимация кадров, кроссфейды через «занавес»,
синхронные субтитры по таймингу озвучки, canvas-дождь, случайные вспышки молний, тряска камеры
и синтезированная через WebAudio атмосфера (ветер, ливень, раскаты грома).
