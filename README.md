# БОЕВОЙ КОНТИНЕНТ — короткометражный фильм

Эпический фэнтези-фильм (1 мин 18 с, 1920×1080, 30 fps) в духе «Боевого континента» (Douluo Dalu):
парящие острова, боевые души, великие секты и война против неба.

**Файл:** `БОЕВОЙ_КОНТИНЕНТ.mp4` · русская озвучка, музыка, субтитры, cinemascope-кадры, кен-бёрнс, титры.

## Как пересобрать
```bash
pip install --break-system-packages imageio-ffmpeg   # или системный ffmpeg
python3 build_film.py     # сегменты (кэш в build/seg) + счёт + финальный монтаж
REBUILD=1 python3 build_film.py   # перерендер с нуля
```
Исходники: `assets/` — кадры, `audio/` — озвучка по репликам, `make_score.py` — синтез саундтрека,
`build_film.py` — монтаж (cinemascope 2.39:1, zoompan, зерно, виньетка, субтитры, склейка, микс).
